================================================================================
  存款保险申报表审核工具 — 使用说明（简易版）
================================================================================

一、这个程序是干什么的
──────────────────────
把银行报送的一堆报表读进来，自动做两件事：

  1. 生成一张《保费基数核对表》——把「存款归属核对（来自 A1411/A2411）」、
     「会计科目核对（来自科目余额表）」、「被保险存款申报表 IRP001」三块
     数据放在同一张表里，按模板公式逐级算好合计数，并在“校验”页给出差额。
  2. 生成一张《校验表》报告——逐项比较上述数据与 IRP001/IRP002，
     告诉你每一项是一致的还是有差异（有差异会把两个数值都列出来）。


二、怎么启动
────────────
提供三个打包版本（解压后直接运行，无需安装 Python）：
· Windows 7 64 位：CunBaoTool_Win7_x64.zip → 存保审核工具_Win7_x64.exe
· Windows 7 32 位：CunBaoTool_Win7_x86.zip → 存保审核工具_Win7_x86.exe
· 银河麒麟 V10（x86_64）：CunBaoTool_KylinV10_x64.zip → 存保审核工具
    chmod +x 存保审核工具 && ./存保审核工具
    （或在文件管理器里允许执行后双击；依赖缺 libxcb/libxkbcommon 时按提示安装）
· 另外也提供 Windows 10/11 版本：存保审核工具.exe。
· 源码运行：python3 gui.py。
· 首次启动若提示缺少字体/依赖，按提示安装即可（Windows 上一般不需要装任何东西）。
· 启动后先显示带《存款保险》主题背景图的首页，页面上只有
  「存款保险申报表非现场审核助手」和「开始核查」「银行类型 / 模板设置…」两个按钮；
  点「开始核查」进入核查功能，功能界面左上角的「← 返回首页」可以回到首页。


三、银行类型与模板（绑定方式）
──────────────────────────────
· 顶部「银行类型 / 模板绑定」区域：下拉选择银行机构类型，右侧显示该类型
  当前绑定的模板文件与状态（✓ 存在 / ✗ 缺失）。
· 每种银行类型绑定一个《保费基数核对表》模板文件；绑定关系自动保存，
  下次打开仍生效。
· 「更换绑定模板…」：为当前银行类型选择其他 .xlsx 模板文件（直接改绑）。
· 「管理银行/模板…」打开管理窗口，可以：
    - 新增银行类型（可沿用当前银行的模板，或使用内置默认模板）；
    - 重命名 / 删除银行类型（只删绑定关系，不删除模板文件）；
    - 更换绑定模板 / 恢复默认模板 / 打开模板；
    - 导入模板（新增模板）：把 .xlsx 复制到模板库并登记，可立即绑定；
    - 打开模板库文件夹。
· 模板要求：.xlsx / .xlsm；必须含「保费基数核对表」工作表；建议同时含
  「校验」工作表（否则生成时不会输出校验页差额）。
· 绑定关系保存在 bank_bindings.json：程序目录可写时存在程序目录（便携），
  否则存在用户配置目录；管理窗口顶部会显示具体路径。
· 如果绑定模板被删除/移动，生成时会自动回退到该银行类型的内置默认模板，
  日志里会提示；建议用「更换绑定模板…」重新指定文件。


四、准备：把文件放到同一个文件夹
────────────────────────────────
新建一个文件夹（例如“2026年9月崇阳”），把银行报送的这些文件放进去即可，
程序按文件名关键词自动识别，不用手工指定：

  文件名里含          放的是什么                        是否必须
  ────────────────────────────────────────────────────────────────
  A1411               资产负债项目月报表（人民币）       必须
  A2411               资产负债项目月报表（外币）         必须
  科目余额表 或
  科目余额查询报表     科目余额（会计科目核对用）         生成核对表必须
  IRP001 或
  被保险存款申报表     被保险存款申报表                   必须
  IRP002             存款账户统计表                     可选（校验用）
  附件2 / 附件3 / 附件4  公积金 / 社保 / 高管存款明细     可选
  附件5              银行报送的保费基数核对表            可选（自动读调整值）

提示：WPS/Excel 打开文件时产生的临时锁文件（.~xxx、~$xxx）程序会自动忽略。


五、三步操作（按顺序点）
────────────────────────
进入「开始核查」后，按下面三步依次操作：

第 1 步：生成保费基数核对表
  · 界面上方选择“工作目录”= 第三步准备的文件夹；
  · 检查“调整值设置”表格（见第六节），确认金额正确；
  · 点「1. 生成保费基数核对表」。
  · 结果：工作目录下生成 保费基数核对表_已生成.xlsx（三块数据 + 校验页）。

第 2 步：执行数据校验
  · 点「2. 执行数据校验」。
  · 结果：日志区逐项列出比较结果；IRP002 存在时会一并做 IRP002 vs IRP001 校验。
    （IRP002 是季报，没有该文件时会跳过 IRP002 部分。）

第 3 步：生成校验报告
  · 点「3. 生成校验报告」。
  · 结果：工作目录下生成 校验报告.xlsx，格式同《校验表（新）》：
      没有数据的格子 → “无对应数据”
      核对一致的格子 → “核对一致”
      核对不一致的格子 → 直接列出两个数值（并标红）

说明：第 1 步生成的表是后面两步的基础；每次都请先“生成”再“校验/报告”，
      否则用的是上次的旧表。


六、调整值怎么填
────────────────
调整值是“源数据与申报表之间的口径差异”，程序会把它加到正确的合计项上。
表格里一行一个项目，需要看懂三列：

  用途  · 会计科目核对：调整会计科目的合计数（个人/单位/其他合计项）
        · 存款归属核对：只影响“校验页”里存款归属与 IRP001 的比较

  对象  · 个人存款 / 单位存款：只影响一侧
        · 个人↔单位：一增一减（个人加、单位减），个体工商户选这个
        · 财政性存款 / 非存款类金融机构存款 / 高级管理人员 / 不予保险的其他存款

  方式  · 会计科目核对：增加＝加进合计，扣减＝从合计里减掉
        · 存款归属核对：扣减＝从 IRP001 本金里扣掉该金额（久悬户就是这种），
                        增加＝加回

默认给了四条标准项（改金额即可用）：
  个体工商户本金   会计科目核对  个人↔单位  本金      增加
  个体工商户利息   会计科目核对  个人↔单位  应付利息  增加
  个人久悬户       存款归属核对  个人存款  本金      扣减
  单位久悬户       存款归属核对  单位存款  本金      扣减
其中前两条是固定标准项，不可删除（不适用时把金额改成 0）。

· 点「＋ 添加项目」可加任意项目（比如“历史久悬未取款转收入（单位部分）”，
  用途选会计科目核对、对象选单位存款、方式选增加）。
· 点「从附件5读取」：按银行报送的附件5（保费基数核对表）里
  “差额说明”列前四格（旧模板 Q7~Q10 / 新模板 P7~P10）自动重建四条
  标准项并填好金额。
· 调整值会自动保存在工作目录的 调整值配置.json，下次打开自动载入，
  切到别家机构的目录时会自动载入该目录的配置。
· 注意：如果用的是去掉了“符号”列的新版模板（模板1019），新版模板里
  没有久悬户的科目录入行，久悬户要补两条调整项——一条“会计科目核对/
  增加”（让会计科目合计含久悬户）、一条“存款归属核对/扣减”（比较
  IRP001 时扣除）。只补一条会显示约 250 万元的假差异。


七、两张产出表怎么看
────────────────────
1) 保费基数核对表_已生成.xlsx
   主表：存款归属（万元，来自 A1411/A2411）、会计科目（元，来自科目
   余额表）、IRP001（元）三块，最后是“差额说明”列（前四格为调整值）。
   列位按模板自动识别：旧版模板为 C~F / G~M / N~P / Q，新版模板
   （去掉“符号”列）为 C~E / F~L / M~O / P。
   合计行都是按模板公式算好的数值；被调整过的合计单元格带批注，写明
   “模板公式结果 ± 调整项 = 最终值”，鼠标悬停即可倒查。
   校验页：B列＝存款归属标志（0一致/1不一致），C列＝存款归属差额（万元），
   D/E/F列＝会计科目本金/利息/合计标志（0一致/1不一致）。

2) 校验报告.xlsx
   B列＝存款归属核对 vs 会计科目核对（本金，万元；会计科目已扣久悬户调整）
   C~E列＝存款归属核对 vs IRP001：
       存款归属口径不含久悬户，比较时以「IRP001 本金 − 久悬户调整额」
       （个人=c3、单位=c4；优先取调整项配置，其次取核对表/附件5 的
       差额说明列）与存款归属比较；扣减后一致即显示“核对一致”。
   F~H列＝被保险存款生成表（会计科目）vs IRP001：
       直接比较、不做久悬户调整，差异会如实标红
       （例如个人存款因科目余额表不含久悬户，会比 IRP001 少 2,506,692.69 元）。
   红底格子＝需要关注的不一致项，格子里直接写着两个数值。


八、几个常用操作
────────────────
· 改模板（调科目代码、行说明、公式、报告栏目）：
  点「更换绑定模板…」或「管理银行/模板…」→「打开模板」，
  用 Excel/WPS 改完保存即可（绑定关系不变）；也可把模板另存为
  其他文件后用「更换绑定模板…」改绑到新文件。
· 换一家银行/一种模板：
  打开「管理银行/模板…」，新增银行类型、导入模板并绑定即可；
  切换银行类型后，模板与取数口径随之切换。
· 找不到文件：在文件列表里点右侧「...」手动选择即可。
· 打开的是旧文件：程序每次都会重写输出文件；如果打开的表里数值和日志
  不一致，说明打开的是以前生成的旧文件（可看标题单元格批注里的生成时间）。
· 校验页显示“不一致”怎么办：先确认调整值（第六节的表）是否正确，
  调整值无误仍有差异，说明申报数据本身存在差异，需要回业务系统核查。


九、常见问题
────────────
Q: 提示“缺少必要文件”？
A: 生成核对表需要 A1411、A2411、科目余额表、IRP001 四类文件；
   校验/报告需要 IRP001 和已生成的核对表。确认文件都放在工作目录里。

Q: 生成的表里某些行是空的？
A: 说明模板里那几行没有填“子项代码/科目代码”，程序不会替你猜数；
   日志会提示“模板公式 xxx 引用了 xxx，但该行没有子代码”，按提示补模板即可。

Q: 单位/个人存款与 IRP001 差一笔钱，怎么处理？
A: 用“调整值”补：在表里加一条「会计科目核对 · 对应对象 · 本金 · 增加 差额」
   即可（差额取银行附件5 或情况说明里的数）。存款归属一侧的差异同理，
   用“存款归属核对”类项目、方式选扣减。

Q: 麒麟系统上双击没反应？
A: 请确认有图形桌面（ssh 下打不开界面）；缺少运行库时安装
   libxcb / libxkbcommon 系列（桌面版麒麟一般自带）；中文字体缺失可
   sudo apt install fonts-noto-cjk。
